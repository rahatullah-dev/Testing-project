# Tech4Edges Practice Website

A small responsive HTML and CSS website created for learning Git and GitHub.

## Files

- `index.html` — page structure and content
- `style.css` — layout, colors, typography, and responsive styles

## Run locally

Open `index.html` in your browser, or open the folder in VS Code and use a local preview extension.

## Git practice goal

1. Keep `main` as the stable branch.
2. Create a feature branch (for example, `feature-homepage`).
3. Make a small change and test it.
4. Commit and push the feature branch.
5. Open a Pull Request and merge it into `main`.

This is a learning project. The contact email uses the reserved `.example` domain and is not a real contact address.
